# 地面机器人规划与执行

地面分支已经接入原生 ROS 2 局部 RRG、全局图、返航、后台扩图及路径复查。它使用三维占据地图向下投影得到地面支撑，按地形生成完整折线。外部里程计与轨迹表示车体基座高度；图内部保留原算法的 `ground + max_ground_height` 规划高度，输出时转换为 `ground + robot_height`。

## 算法

五射线投影对应原 `projectSample`：中心射线与 X/Y 方向四条备用射线。占据快照使用首个占据体素的上表面；未知观测不会被跳过。备用射线用世界地面高度，修正原实现抬高射线起点后仍沿用原高度导致的 0.5 m 偏差。

每条边保存完整地形折线和实际长度，检查每段上坡角、下坡角、机器人扫掠盒及连续地面支撑。局部和全局最短路逐方向计算：某坡允许上行而禁止下行时仍保留可用方向。全局时间预算计算“候选点到家”的有向距离。地图改变后重新计算地形边及可达性。

未知地面可以生成悬空局部候选，但车体所在体积仍须为已知自由空间。候选增益逐顶点乘 `exp(-is_hanging * hanging_vertex_penalty)`，再进行路径方向评分。执行输出在首个悬空顶点或非严格可行边之前截断，任务预算采用此前缀的实际长度；候选总长度单独记录。向全局图导出时屏蔽无法通过严格地形边到达的前沿，全局后台扩图和返航始终要求已知支撑。

`ValidatePath` 直接检查收到的车体轨迹，包括坡度、扫掠盒及每半个体素的支撑检查，不把浮空直线重新投影后判为有效。`PathFollower` 的 `robot_type=kGround` 保留规划器分配的偏航；沿用原 PCI 地面模式不做空中偏航平滑的约定。

## 实际运行结果

在 Ubuntu 22.04 ARM64 / ROS 2 Humble 开发容器完成改动包编译及以下模块流程：

| 场景 | 结果 |
| --- | --- |
| 地形投影 | 起伏地形输出三维曲线；陡阶与未知支撑间隙拒绝；侧射线高度正确 |
| 方向不同的坡道 | 上行通过、下行返航拒绝；图更新保留单向可用连接；无可行返航的预算请求拒绝 |
| 允许双向的坡道 | 返回 32 点路线，高差 1 m，曲线长 3.24326 m，大于端点弦长 3.16228 m |
| 原生地形规划 | 192,000 格三维地图；局部图 76 顶点/1,000 边，局部路径 4.31177 m，返航 4.29103 m，高差均 0.30 m |
| 悬空候选 | 图中 94 个悬空顶点；惩罚为 0 时选中 5.66648 m 候选，输出 1.65868 m 可行前缀；惩罚为 5 时改选 2.24403 m 已支撑路线 |
| 原生动作执行 | 局部与返航 2 次动作成功、零中止，337 个轨迹指令点、864 个里程计样本；实际消费者行程约 8.594 m，返回起点 |

动作流程使用按墙钟时间消费轨迹的运动学夹具，消费者不修正 Z，也不重新投影轨迹。它验证了规划—复查—动作—轨迹—里程计闭环，尚未模拟轮胎、地面接触、打滑和悬架。基座相对量化地面的高度误差最大 0.0834 m，小于该场景 0.1 m 体素；这不是实际机器人跟踪误差。独立规划流程与动作流程的返航路径略有不同，因为两者记录的里程计采样不同。

后台服务在本场景调用成功，100 次尝试因历史/范围规则新增 0 个节点；未降低原排除阈值。本节实验使用占据体素支撑；后续接入的 TSDF 距离插值及其独立结果见下节。

## 运行

```bash
ros2 launch gbplanner_local ground.launch.py execution:=true
```

该入口等待外部 `voxel_map`、`odometry` 和轨迹消费者。配置见 `src/gbplanner_local/config/ground.yaml`，示例尺寸仅用于本合成场景。

独立运行工作流会自行启动所需节点：

```bash
ros2 run gbplanner_local ground_terrain_demo
ros2 run gbplanner_local ground_global_demo
ros2 run gbplanner_local ground_hanging_demo
ros2 run gbplanner_local ground_planning_demo.py --start-node --output results/ground_planning/summary.json
ros2 run gbplanner_local ground_execution_demo.py --output results/ground_execution/summary.json
```
